# Experiment 2: Digital Visiting Card Design

## Aim
To design an Android application that displays a digital visiting card containing a company logo at the top right corner, the company name in capital letters aligned to the centre, and the employee's name, job title, phone number, address, email, fax and website — with a horizontal line separating the job title from the phone number.

## Objectives
- To design a static, well-aligned UI using RelativeLayout / ConstraintLayout.
- To position an image using ImageView with alignment attributes.
- To style text using textAllCaps, textStyle and alignment attributes.
- To use a plain View as a horizontal divider instead of a table or image.

## Procedure / Algorithm
1. Create a new Android project using Kotlin and Jetpack Compose.
2. Place the company logo in the res/drawable folder.
3. Design the visiting card in MainActivity.kt using Compose components.
4. Display the company logo at the top-right corner and the company name in capital letters at the centre.
5. Add the employee name, job title, phone number, address, email, fax and website.
6. Insert a horizontal line between the job title and phone number.
7. Arrange and format the components using Compose layout and styling properties.
8. Run the application on the emulator and verify that the visiting card matches the required design.

## Source Code Files
- `app/src/main/AndroidManifest.xml`
- `app/src/main/java/com/example/visitingcard/MainActivity.kt`

## Result
Thus, an Android application to design and display a digital visiting card with the specified layout and formatting requirements was successfully implemented.
